# WebSockets

WebSocket security testing involves identifying vulnerabilities in WebSocket-based communication channels. Unlike HTTP, WebSockets maintain a persistent connection, which introduces different attack surfaces including message injection, cross-site WebSocket hijacking, and handshake manipulation.
