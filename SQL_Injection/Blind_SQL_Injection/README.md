# Blind SQL Injection

Blind SQL injection occurs when the application is vulnerable to SQL injection but the response does not directly reveal the query results. These labs cover techniques for extracting data when the database output is not visible, including conditional errors, conditional responses, time-based delays, and out-of-band (OAST) data exfiltration.
