# Basic SQL Injection

Basic SQL injection vulnerabilities where user input is directly concatenated into SQL queries without proper sanitization. These labs demonstrate the foundational techniques for detecting and exploiting SQL injection in its simplest forms, including retrieving hidden data and bypassing login logic.
