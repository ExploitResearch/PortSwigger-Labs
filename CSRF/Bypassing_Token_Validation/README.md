# CSRF Token Validation Bypasses

A CSRF token is a unique, secret, and unpredictable value that is generated by the server-side application and shared with the client. When issuing a request to perform a sensitive action

The labs below demonstrate different ways CSRF token validation can be broken
when the token is implemented incorrectly. Each lab explores a specific
weakness in token handling.
